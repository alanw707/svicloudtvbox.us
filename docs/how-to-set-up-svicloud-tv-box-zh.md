# 小雲（SviCloud）電視盒安裝指南

這份繁體中文 SviCloud 安裝教學整合官方英文與繁中內容，協助您快速上手小雲系列 Android 串流電視盒，適合用於 svicloudtvbox.us Guides 區塊的繁中版本。

## 小雲能為您做到什麼

- 基於 Android 的串流播放器，提供流暢的直播、隨選影視與卡拉 OK 體驗。
- 支援 Netflix、YouTube、Disney+、Amazon Prime Video 等主流第三方服務。
- 10P+ 版遙控器具備語音搜尋與多語字幕速度調整。
- 適合尋找 Android 串流電視盒、需要國際內容與卡拉 OK 功能的家庭。

### 小雲獨家應用程式

| App | 功能亮點 |
| --- | --- |
| **Yogurt TV / LUCA TV** | 全球直播頻道、影集與電影，隨時隨地透過小雲設備收看。 |
| **Yogurt Kids / LUCA Kids** | 為兒童設計的教育與娛樂內容，包含動畫、互動學習遊戲。 |
| **Cherry TV** | 成人專區，需要密碼才能觀看。 |

> **提醒：** 出廠時沒有預載這些應用程式，需透過 Orz 安裝器自行下載。

## 小雲電視盒快速安裝步驟

1. **連接硬體**  
   以 HDMI 線接上電視，插上電源後盒子會自動開機（前方指示燈亮起）。

2. **選擇語言**  
   首次開機時，使用遙控器方向鍵選擇語言，按 `OK` 後再按 `Next` 進入下一頁。

3. **同意免責聲明**  
   按下「Continue」繼續。

4. **配對語音遙控器**  
   同時按住遙控器的 `VOL-` 與 `VOL+` 直到螢幕顯示配對完成，可啟用小雲 10P+ 語音遙控搜尋功能（限支援型號）。

5. **設定時間日期**  
   確認時區與時間正確，節目表才會顯示準確資訊。

6. **連線 Wi-Fi 或網路線**  
   選擇「Set up WiFi」，挑選正確的網路並輸入密碼；若使用有線網路，直接插入 Ethernet 可獲得最佳穩定度。

7. **安裝小雲專屬 App**  
   - 從主畫面開啟 `Orz` 安裝器。  
   - 輸入網址 `8989c.cc`（會自動導向 6868c.cc）。  
   - 下載 Yogurt TV、Yogurt Kids、Cherry TV、Karaoke KTV 等常用應用，完成 SviCloud TV Box App 安裝流程。

## 安裝後可以做什麼

- 使用遙控器瀏覽主畫面，找到直播、影片點播與設定等選單。
- 需要更多內容時，可自行安裝其他 Android 串流電視盒相容 App，建議選擇可信來源。
- 進入底部的設定頁調整音訊、顯示、網路等個人偏好。

## 功能提示與型號差異

- **Karaoke KTV** 僅支援 SviCloud 10P+。  
- **語音控制** 只適用於 SviCloud 10P+（10S 遙控器不支援）。  
- 多語字幕可調整速度，配合不同節奏需求。

## 常見疑難排解

- 遙控器無法配對：取出電池再裝回，靠近機身重新按 `VOL-` + `VOL+` 進行配對。
- 串流品質不佳：重啟路由器、拉近與 Wi-Fi 的距離，或改用有線網路。
- 允許安裝第三方 App，但務必確認為 Android TV 相容版本。
