## 🚀 5分鐘快速安裝 | 5-Minute Quick Setup

### 1. 連接 Connect
```
電視盒 Box ──HDMI──> 電視 TV
    │
電源線 Power ──> 插座 Outlet
```
插上電源自動開機 | Powers on automatically

### 2. 語言 Language → 條款 Terms
選語言 Select language → 按 Press `OK` → `Next` → 按 Press `Continue`

### 3. 遙控器 Remote
**多數已配對，先試按鍵！Most pre-paired, try first!**
無反應？No response? → 按住 Hold: `音量- VOL-` + `音量+ VOL+`

### 4. 時間 Time
選時區 Select timezone → 確認時間 Confirm time → `Next`

### 5. 網路 Network
**Wi-Fi:** 選網路 Select network → 輸密碼 Enter password
**有線 Wired:** 插網路線更穩定 Plug Ethernet for best stability

### 6. 安裝應用 Install Apps
1. 開 Open **Orz 安裝器 Installer**
2. 輸入 Enter: `8989c.cc` (自動轉向 auto-redirects to 6868c.cc)
3. 下載安裝 Download & install:

| 應用 App | 功能 Function |
|---------|--------------|
| **Yogurt TV/LUCA TV** | 直播/電影 Live/Movies |
| **Yogurt Kids** | 兒童內容 Kids |
| **We Fun KTV** | 卡拉OK Karaoke |
| **Cherry TV** | 成人 Adult (密碼 password) |

### 7. 完成！Done!
開始觀看 Start watching! 🎉
