# 小雲電視盒快速安裝指南

**感謝您購買小雲（SviCloud）電視盒！**

本指南將協助您在幾分鐘內完成安裝並開始使用。

---

## 📦 包裝內容物

請確認包裝內包含以下物品：

- ☐ 小雲電視盒主機 x 1
- ☐ 電源適配器 x 1
- ☐ HDMI 線 x 1
- ☐ 遙控器 x 1
- ☐ 快速安裝指南（本文件）

---

## 🔧 安裝步驟

### 步驟 1：連接硬體

1. 使用 HDMI 線連接電視盒與電視機
2. 將電源適配器插入電源插座
3. 電視盒會自動開機（前方指示燈亮起）

```
[電視盒] ──HDMI線──> [電視]
   │
   └──電源線──> [電源插座]
```

---

### 步驟 2：選擇語言

1. 開機後，使用遙控器方向鍵選擇語言
2. 按下 `OK` 確認
3. 按下 `Next` 進入下一步

---

### 步驟 3：同意使用條款

- 閱讀免責聲明
- 按下「Continue」繼續

---

### 步驟 4：檢查遙控器連接（僅需要時配對）

**大部分遙控器已在出廠時配對完成！**

先試按任意鍵，如果遙控器有反應，請直接跳到步驟 5。

**如需配對（遙控器無反應時）：**

1. 同時按住遙控器的 `音量-` 和 `音量+` 鍵
2. 持續按住直到螢幕顯示配對成功訊息
3. 配對完成後即可使用語音搜尋功能（僅 10P+ 支援）

> **提醒：**
> - 多數用戶不需要此步驟（遙控器已預先配對）
> - 10S 型號不支援語音功能
> - 更換電池後可能需要重新配對

---

### 步驟 5：設定時間與日期

1. 選擇您的時區
2. 確認日期與時間正確
3. 按下 `Next` 繼續

> **提示：** 正確的時間設定確保節目表顯示準確資訊。

---

### 步驟 6：連接網路

**方式 A：Wi-Fi 連線（推薦）**

1. 選擇「Set up WiFi」
2. 從列表中選擇您的 Wi-Fi 網路
3. 輸入 Wi-Fi 密碼
4. 等待連線成功

**方式 B：有線網路（最穩定）**

- 直接將網路線插入電視盒的 Ethernet 插孔
- 系統會自動連線

> **建議：** 有線網路提供最佳穩定性和速度。

---

### 步驟 7：安裝小雲專屬應用程式

完成網路連線後，開始安裝小雲應用程式：

1. 從主畫面開啟 **Orz 安裝器**
2. 輸入安裝網址：`8989c.cc`
   （系統會自動轉向 `6868c.cc`）
3. 下載並安裝以下常用應用：

   #### 必裝應用程式清單：

   | 應用程式 | 說明 |
   |---------|------|
   | **Yogurt TV / LUCA TV** | 全球直播頻道、電影、電視劇 |
   | **Yogurt Kids / LUCA Kids** | 兒童教育與娛樂內容 |
   | **Cherry TV** | 成人頻道（密碼保護） |
   | **We Fun / 閤家歡 KTV** | 居家卡拉 OK（僅 10P+） |
   | **地區直播** | 各地區本地頻道 |

4. 等待所有應用程式安裝完成

## ❓ 疑難排解

### 問題 1：遙控器無反應

**解決方法：**
1. 檢查電池是否正確安裝
2. 如果仍無反應，進行配對：
   - 將遙控器靠近電視盒
   - 同時按住 `音量-` + `音量+` 直到配對成功
3. 如配對失敗：
   - 取出電池等待 10 秒
   - 重新裝回電池
   - 再次嘗試配對

---

### 問題 2：網路連線不穩定或速度慢

**解決方法：**
1. 重新啟動路由器
2. 將電視盒移近 Wi-Fi 路由器
3. 改用有線網路連接（推薦）
4. 檢查其他設備是否佔用大量頻寬

---

### 問題 3：無法安裝應用程式

**解決方法：**
1. 確認網路連線正常
2. 重新輸入安裝網址 `8989c.cc`
3. 清除 Orz 安裝器快取後重試
4. 聯繫客服獲取最新安裝網址

---

### 問題 4：畫面或聲音品質不佳

**解決方法：**
1. 檢查 HDMI 線連接是否牢固
2. 嘗試更換 HDMI 線
3. 調整電視的顯示設定
4. 進入設定調整音訊和視訊選項
