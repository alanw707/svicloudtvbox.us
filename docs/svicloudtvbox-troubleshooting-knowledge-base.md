# SVICLOUDTVBOX.US Troubleshooting Knowledge Base

Internal support notes for repeat troubleshooting cases. This is not customer-facing marketing copy.

## 2026-05-10 — Remote replacement after failed troubleshooting

**Scenario:** Customer reports the remote still does not work after trying the recommended troubleshooting steps and calling support.

**Support decision:** Treat the replacement request as reasonable. Do not keep looping the customer through the same pairing/battery steps once they have already tried them.

**Action:** Approve a replacement remote when the order/warranty context checks out, then ask the customer to confirm shipping details before sending it.

**Suggested customer reply:**
> Thanks for trying those steps and calling support. Since the remote is still not working, we can send a replacement remote. Please confirm your shipping address and order number so we can get it shipped out.

**Tags:** remote, pairing, replacement, warranty, customer-support
