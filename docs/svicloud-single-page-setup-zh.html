小雲電視盒快速安裝卡 SviCloud TV Box Setup Guide

🚀 快速安裝 Quick Setup

1. 連接 Connect

電視盒 HDMI→電視 | 插電源自動開機 Powers on automatically

2. 語言→條款 Language→Terms

選語言 Select language → OK → Next → Continue

3. 遙控器 Remote

多數已配對，先試按鍵 Most pre-paired, try first
無反應？Hold: VOL- + VOL+

4. 時間 Time

選時區 Timezone → 確認 Confirm → Next

5. 網路 Network

Wi-Fi: 選網路→輸密碼 Select→Enter password
有線: 插網路線(更穩定) Plug Ethernet (best)

6. 安裝應用 Install Apps

開 Open Orz → 輸入 Enter: 8989c.cc

應用 App功能 Function
Yogurt TV直播/電影 Live/Movies
Yogurt Kids兒童 Kids
We Fun KTV卡拉OK Karaoke
Cherry TV成人(密碼) Adult

7. 完成！Done!

開始觀看 Start watching! 🎉
