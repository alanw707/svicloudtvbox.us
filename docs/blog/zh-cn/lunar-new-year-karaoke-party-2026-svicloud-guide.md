<h2 class="blog-section__title">Troubleshooting Common Karaoke Issues</h2>
<div class="blog-faq">
<article>
<h3>Microphone not pairing with SVICLOUD?</h3>
<p><strong>Quick Fix:</strong> Hold VOL- + VOL+ on remote for 5 seconds until LED blinks. On mic, press power + Bluetooth simultaneously. If still failing, try these steps:</p>
<ul>
<li>Navigate to Settings → Bluetooth → Forget All Devices</li>
<li>Restart SVICLOUD (unplug for 10 seconds)</li>
<li>Check mic battery level (low power causes pairing failures)</li>
<li>Move within 10 feet of TV box during initial pairing</li>
</ul>
</article>
<article>
<h3>Echo or feedback during singing?</h3>
<p><strong>Root Causes:</strong> TV speakers + external speakers playing simultaneously, or mic too close to speaker output.</p>
<p><strong>Solutions:</strong></p>
<ul>
<li>Disable TV speakers: Settings → Audio → TV Speakers OFF (use external speakers only)</li>
<li>Reduce mic sensitivity: WeFun app → Settings → Mic Gain (lower by 10-20%)</li>
<li>Position speakers forward, microphones 6+ feet away from speaker cones</li>
<li>Enable echo cancellation: WeFun app → Audio Settings → Echo Reduction ON</li>
</ul>
</article>
<article>
<h3>Song not found in WeFun library?</h3>
<p><strong>Workarounds:</strong></p>
<ul>
<li>Try alternative search: Artist name + song title (e.g., &#8220;鄧麗君 月亮&#8221;) instead of just song title</li>
<li>Check spelling: Traditional vs Simplified Chinese can affect results</li>
<li>Browse by artist: WeFun → Artists → Find singer → See full catalog</li>
<li>Request additions: WeFun has song request form inside app (Settings → Suggest Songs)</li>
</ul>
</article>
<article>
<h3>Lyrics out of sync with music?</h3>
<p><strong>Fixes:</strong></p>
<ul>
<li>Restart current song: WeFun → Menu → Restart Track</li>
<li>Clear app cache: Settings → Apps → WeFun → Clear Cache (not data)</li>
<li>Check internet speed: Run speed test, need 10+ Mbps for smooth streaming</li>
<li>Use Ethernet instead of Wi-Fi if sync issues persist</li>
</ul>
</article>
<article>
<h3>Volume balance issues (music too loud, vocals too quiet)?</h3>
<p><strong>Adjustments:</strong></p>
<ul>
<li>WeFun app → Settings → Audio Mixer</li>
<li>Music volume: 60-70% (background)</li>
<li>Vocal volume: 80-90% (lead)</li>
<li>Echo/reverb: 20-30% (adds depth without muddiness)</li>
<li>Test with one singer, adjust, save preset for party</li>
</ul>
</article></div>
