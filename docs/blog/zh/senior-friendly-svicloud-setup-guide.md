## 給子女的安裝指南：幫父母設定好再離開

### 第一步：硬體連接（5 分鐘）

1. **HDMI 連接電視**
   - 找到電視背後的 HDMI 孔（通常標示 HDMI 1、2、3）
   - 插入 HDMI 線（一頭接電視盒，一頭接電視）
   - 記住是 HDMI 幾號（例如 HDMI 2）

2. **插上電源**
   - 電源線接電視盒，插座插電
   - 自動開機，電視盒指示燈亮起

3. **電視切換訊號源**
   - 按電視遙控器的「Input」或「Source」鍵
   - 選擇剛才插的 HDMI 號（例如 HDMI 2）
   - 看到小雲電視盒開機畫面即成功

**📸 建議：用手機拍下 HDMI 號碼，給父母留著！**

### 第二步：網路設定（3 分鐘）

**方案 A：有線網路（最穩定，推薦）**
1. 用網路線連接電視盒和路由器
2. 系統自動連線，無需設定
3. 看到「已連線」即可進入下一步

**方案 B：Wi-Fi 無線網路**
1. 開機後選擇「Wi-Fi 設定」
2. 找到家裡的 Wi-Fi 名稱（例如：Home-WiFi）
3. 輸入 Wi-Fi 密碼
4. 連線成功後進入下一步

**💡 提示：寫下 Wi-Fi 名稱和密碼貼在電視盒旁，方便日後查詢！**

### 第三步：語言與時區（2 分鐘）

1. 選擇語言：**繁體中文**（台灣、香港）或 **簡體中文**（大陸）
2. 選擇時區：
   - 加州、內華達、華盛頓：**太平洋時間 (PST)**
   - 德州、伊利諾：**中部時間 (CST)**
   - 紐約、佛州：**東部時間 (EST)**
3. 確認時間正確，按「下一步」

### 第四步：教父母基本操作（10 分鐘）

#### 操作 1：開關機

- **開機**：按遙控器紅色電源鍵，等 30 秒
- **關機**：再按一次紅色電源鍵
- **省電模式**：不用時讓它自動休眠（30 分鐘無操作）

#### 操作 2：看直播頻道

1. 按「主頁」鍵回首頁
2. 選擇「直播」或「Yogurt TV」
3. 用方向鍵選頻道，按「確認」鍵播放
4. 按「向上/向下」鍵換台

**讓父母練習換台 5 次，直到熟悉！**

#### 操作 3：語音搜尋

1. 按住麥克風鍵不放
2. 說「TVB」或「新聞」
3. 放開麥克風鍵
4. 系統顯示搜尋結果，選擇觀看

**讓父母練習 3 次，克服語音搜尋恐懼！**

#### 操作 4：調整音量

- 按「音量+」變大聲
- 按「音量-」變小聲
- 也可以用電視遙控器調整

#### 操作 5：看重播節目

1. 按「主頁」鍵
2. 選擇「隨選影片」或「LUCA TV」
3. 用方向鍵選電影或戲劇
4. 按「確認」鍵播放

### 第五步：設定常用頻道（5 分鐘）

幫父母把常看的頻道加入收藏：

1. 打開直播頻道列表
2. 找到父母愛看的頻道（例如 TVB、鳳凰衛視、CCTV）
3. 按遙控器「星號 ⭐」鍵加入最愛
4. 重複步驟 2-3，加入 5-10 個頻道
5. 按「主頁」→「我的最愛」即可快速觀看

**📋 建議列表（根據父母喜好調整）：**
- TVB 翡翠台（香港新聞、劇集）
- 鳳凰衛視（時事新聞）
- CCTV-4（中國央視）
- 東森新聞（台灣新聞）
- 民視（台劇）
- 八大戲劇（台劇）

1. 開機

3. 選想看的電影
4. 享受家庭影院

### 常見狀況處理

#### 狀況 1：畫面黑屏

**原因：** 電視訊號源沒切換到 HDMI

**解決方法：**
1. 按電視遙控器「Input」或「Source」鍵
2. 選擇之前記下的 HDMI 號（例如 HDMI 2）
3. 看到小雲畫面即可

#### 狀況 2：遙控器沒反應

**原因：** 電池沒電或沒配對

**解決方法：**
1. 更換 2 顆 AAA 電池
2. 同時按住「音量-」+「音量+」鍵 3 秒
3. 看到配對成功訊息即可

#### 狀況 3：頻道卡頓

**原因：** 網路速度慢

**解決方法：**
1. 暫停其他設備的下載或串流
2. 把電視盒靠近路由器
3. 改用有線網路連接
4. 調低畫質：設定 → 畫質 → 選 720p

#### 狀況 4：找不到頻道

**原因：** 頻道更新或下架

**解決方法：**
1. 按「主頁」→「設定」→「系統更新」
2. 更新到最新版本
3. 重新啟動電視盒
4. 仍找不到請聯繫客服

#### 狀況 5：忘記操作

**解決方法：**
1. 查看貼在電視旁的操作筆記
2. 打電話給子女協助
3. 撥打客服專線：+1 (520) 641-7021
