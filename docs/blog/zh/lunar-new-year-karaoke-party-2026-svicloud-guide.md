      <p><strong>快速修復：</strong> 同時按住遙控器 VOL- + VOL+ 5秒直到 LED 閃爍。在麥克風上，同時按電源 + 藍牙。如果仍然失敗，嘗試這些步驟：</p>
      <ul>
        <li>導航至 設定 → 藍牙 → 忘記所有裝置</li>
        <li>重啟 SVICLOUD（拔掉電源10秒）</li>
        <li>檢查麥克風電量（低電量導致配對失敗）</li>

    <article>
      <h3>唱歌時有回音或雜音？</h3>
      <p><strong>根本原因：</strong> 電視音響 + 外接音響同時播放，或麥克風太靠近音響輸出。</p>
      <p><strong>解決方案：</strong></p>
      <ul>
        <li>停用電視音響：設定 → 音訊 → 電視音響 關閉（僅使用外接音響）</li>
        <li>降低麥克風敏感度：WeFun 應用程式 → 設定 → 麥克風增益（降低10-20%）</li>
        <li>音響朝前擺放，麥克風距離音響錐體6呎以上</li>
        <li>啟用回音消除：WeFun 應用程式 → 音訊設定 → 回音減少 開啟</li>
      </ul>
    </article>

    <article>
      <h3>WeFun 資料庫找不到歌曲？</h3>
      <p><strong>變通方法：</strong></p>
      <ul>
        <li>嘗試替代搜尋：歌手名 + 歌名（例如「鄧麗君 月亮」）而非僅歌名</li>
        <li>檢查拼寫：繁體與簡體中文可能影響結果</li>
        <li>按歌手瀏覽：WeFun → 歌手 → 尋找歌手 → 查看完整目錄</li>
        <li>申請添加：WeFun 應用程式內有歌曲請求表（設定 → 建議歌曲）</li>
      </ul>
    </article>

    <article>
      <h3>歌詞與音樂不同步？</h3>
      <p><strong>修復：</strong></p>
      <ul>
        <li>重新開始當前歌曲：WeFun → 選單 → 重新開始曲目</li>
        <li>清除應用程式快取：設定 → 應用程式 → WeFun → 清除快取（非資料）</li>
        <li>檢查網路速度：執行速度測試，需要10+ Mbps流暢串流</li>
        <li>如果同步問題持續，使用乙太網而非 Wi-Fi</li>
      </ul>
    </article>

    <article>
      <h3>音量平衡問題（音樂太大聲、人聲太小聲）？</h3>

        <li>音樂音量：60-70%（背景）</li>
        <li>人聲音量：80-90%（主角）</li>
        <li>回音/混響：20-30%（增加深度不混濁）</li>
        <li>用一位歌手測試、調整、儲存派對預設</li>
      </ul>
