<p>這篇不是規格複讀，而是一戶拉斯維加斯三口之家的真實安裝記錄：從拆箱、網速調校，到把爸媽常看的 TVBS、孩子的 Disney+ 放到同一支遙控器裡，全程 35 分鐘完成，連 Wi‑Fi Mesh 擺位與有線/無線的差異都量給你看。</p>
<h2>家庭環境與網速現況</h2>
<ul>
<li>住宅：雙層 townhome，約 1,900 平方英尺，客廳在一樓角落。</li>
<li>網路：Cox 500 Mbps (Gigablast)；原本只有 eero 6 兩顆 Mesh，客廳角落 Wi‑Fi 約 38–55 Mbps。</li>
<li>裝置：SVICLOUD 10P+；客廳電視櫃預留了 LAN 插孔。</li>
</ul>

<p><strong>結論：</strong>有 LAN 直接用有線；沒有 LAN 就把 Mesh 衛星移到離電視 &lt;10 英尺，4K 串流的緩衝圈會消失。</p>
<h2>安裝時間線（共 35 分鐘）</h2>
<ol>
<li><strong>0–5 分鐘：</strong> 插電、接 HDMI，遙控器裝電池，長按 OK + 音量鍵配對。</li>
<li><strong>5–15 分鐘：</strong> 先用 Wi‑Fi 連線，登入 Google 帳號下載 Disney+、YouTube；同時在路由器介面把 eero 衛星移到客廳，確認 5GHz 信號。</li>
<li><strong>15–25 分鐘：</strong> 在設定裡切到 LAN，重開一次，Speedtest 穩定在 400+ Mbps。</li>
<li><strong>25–35 分鐘：</strong> 把常用 App 排序在首頁，語音搜尋測試（中英文都能辨識），幫爸媽設家長 PIN，開啟字幕預設。</li>
</ol>
<h2>內容實際收看</h2>
<ul>
<li><strong>爸媽：</strong> TVBS、東森新聞、民視，連續播放 3 小時沒掉線；字幕預設繁體中文。</li>
<li><strong>孩子：</strong> Disney+ 卡通 + YouTube Kids，語音指令「Play Bluey on Disney Plus」可直接啟動。</li>
<li><strong>運動：</strong> CBS + ESPN 週末體育直播，LAN 模式下 4K 只在進場廣告時出現一次短暫 0.5 秒緩衝。</li>
</ul>
<h2>Wi‑Fi / Mesh 調校心得</h2>
<ul>
<li>先用 Wi‑Fi 完成初次設定，再切換 LAN；沒有 LAN 時，把 Mesh 衛星放在電視右側矮櫃，保持 1–1.5 公尺。</li>
<li>eero 把 2.4GHz / 5GHz 都開，SVICLOUD 10P+ 會優先選 5GHz；若家裡有微波爐或藍牙喇叭，優先避開它們。</li>
<li>路由器別用極端的「頻道自動」，固定在 5GHz 44 或 149、頻寬 80MHz；避免夜間頻道切換造成卡頓。</li>
</ul>
<h2>真實問題與解法</h2>
<ul>
<li><strong>遙控器偶爾延遲：</strong> 在藍牙設定裡移除舊配對，重按 OK + 音量鍵；延遲就消失。</li>
<li><strong>Disney+ 要求更新：</strong> 進 Google Play 直接更新，5 分鐘完成；更新後重新登入一次。</li>
<li><strong>字幕慢半拍：</strong> 播放設定把字幕改成「預設 +0.5 秒」，新聞台對嘴更貼合。</li>
</ul>
<h2>成本與帳單</h2>
<ul>
<li>原 Cox Cable 電視套餐約 118 美元／月，換成 SVICLOUD 10P+ 後只保留網路（約 79 美元／月），節省近 40 美元／月；同時 eero Mesh 繼續當主路由。</li>
<li>兩週觀察沒有額外月費，內容更新靠系統自動推播。</li>
</ul>
<h2>如果你也要在美國安裝</h2>
<ul>
<li>先看客廳有沒有可用 LAN；沒有的話，把 Mesh 衛星移近電視並做一次 Speedtest（&gt;150 Mbps 就夠 4K）。</li>
<li>第一次開機就把常用 App 裝好、排序；語音指令中英混說都能辨識，長輩用中文、孩子用英文沒問題。</li>
<li>有卡頓先檢查 Wi‑Fi 頻道與 Mesh 位置，再考慮改接 LAN；必要時可預約客服遠端排查。</li>
</ul>
