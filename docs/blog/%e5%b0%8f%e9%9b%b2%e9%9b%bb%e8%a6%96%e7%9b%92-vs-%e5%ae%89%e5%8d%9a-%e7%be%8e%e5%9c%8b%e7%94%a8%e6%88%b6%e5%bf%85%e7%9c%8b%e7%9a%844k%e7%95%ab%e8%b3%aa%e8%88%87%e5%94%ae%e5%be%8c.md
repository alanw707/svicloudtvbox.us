## What to check

For each exact model, verify resolution, codecs and ports. For each seller, check the written warranty, return destination and support channel. These are separate checks: brand specifications do not define a marketplace seller's service.

If you already own a working unit, solve cable, app or network issues before replacing it. Compare current SVICLOUD models only when an identified feature or service need justifies the change.
