## 🚀 快速安裝（5-10 分鐘）

### 1️⃣ 連接設備
```
電視盒 ──HDMI──> 電視
  │
  └──電源線──> 插座
```

### 2️⃣ 開機設定
- 選擇語言 → 按 `OK` → 按 `Next`
- 同意條款 → 按「Continue」

### 3️⃣ 檢查遙控器
- 先試按任意鍵（多數已預先配對）
- 如無反應：同時按住 `音量-` + `音量+`
- 等待配對成功（僅 10P+ 支援語音）

### 4️⃣ 設定時間
- 選擇時區 → 確認日期時間 → `Next`

### 5️⃣ 連接網路
**Wi-Fi：** 選擇網路 → 輸入密碼
**有線：** 插入網路線（更穩定）

### 6️⃣ 安裝應用
1. 開啟 **Orz 安裝器**
2. 輸入：`8989c.cc`
3. 下載安裝：
   - ✅ Yogurt TV（直播）
   - ✅ Yogurt Kids（兒童）
   - ✅ We Fun KTV（卡拉OK，僅10P+）
   - ✅ Cherry TV（成人，密碼保護）

### 7️⃣ 開始使用！
完成！享受您的小雲電視盒！

## 🔧 快速疑難排解

| 問題 | 解決方法 |
|------|---------|
| 🎮 遙控器無反應 | 檢查電池 → 按住音量-/+ 配對 |
| 📶 網路不穩 | 重啟路由器 / 改用有線 |
| 📱 無法安裝 App | 檢查網路 → 重新輸入網址 |
| 🖥️ 畫面模糊 | 檢查 HDMI 連接 → 調整電視設定 |
